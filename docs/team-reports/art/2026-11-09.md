# Art audit, 2026-11-09

First run. One-time audit, asked for by the owner. Nothing in the game was changed.

## Summary

1. There is no single art manager. Each panel has its own **Art** list, in its prefab in `Assets/UI/Board/Panels/`. The step-by-step guide is `docs/BOARD_UI.md`.
2. This file is the master list: every picture on the board, panel by panel, with the file it uses.
3. The board has 225 Art list entries. All are filled. No file is missing. Every file in `Assets/UI/Board/Art/` is used.
4. Waiting for real art: 10 stand-in entries on the board, 8 empty slots in the ship's rooms, and five screens with no pictures at all.
5. Some pictures are not on any Art list. The code swaps them. Section 3 says where to change each one.

## How to change a picture

Open **Starwolf → Art**. Find the picture. Drop the new one onto its box.

The window also lists the pictures the code swaps (section 3), and the pictures in each open scene. If the old picture is used in other places, it asks: **Only here**, **Cancel** or **Everywhere**. Many stand-ins use `Shapes/circle.png`. To replace one stand-in, pick **Only here**. The steps are in `docs/BOARD_UI.md`, under "How to change a panel's art".

The other way, in the prefab:

1. Open the panel's prefab in `Assets/UI/Board/Panels/` (double-click it).
2. Click the panel's top object. Find the **Art** list on its panel script. The frame pieces (Frame, ToolRail, SystemsRail, TimeControl, Console, AlarmStrip, SignalBox) have it on the **Art List** script.
3. Find the entry by name. Drop the new picture into its **Sprite** box. Every image in its **Images** list changes.
4. Save the prefab.

New picture files: set **Texture Type** to **Sprite (2D and UI)**, and turn **sRGB (Color Texture)** off under **Advanced**. Put the file in the panel's folder in `Assets/UI/Board/Art/`. Keep the old file name if you are replacing a file in place.

Each panel also has a **Fonts** list under the Art list. It works the same way.

## How this was made

A one-time script read every prefab in `Assets/UI/Board/Panels/` and every scene in `Assets/Scenes/Tactical/`. It listed each Art list entry, its file, and its images. It also listed images that have a picture but are not on an Art list, and checked each picture's import settings. Unity was not used. The script is not saved in the project.
