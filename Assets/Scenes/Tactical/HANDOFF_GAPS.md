# Handoff Gaps

This file lists every gap found in the Claude Design handoff package
(`Assets/UI2/Claude Design handoff/export/`, generated 2026-09-27). At the end of the integration it
becomes one request to Claude Design, asking them to fill every gap at once.

Record numbers like "drawn #41" are positions in the lists in `layout/layout.json`, counted from 0.
The details behind each row are in `UI_INTEGRATION_LOG.md` and in the comments of
`Assets/Editor/HandoffBoardBuilder.cs`.

## How to keep this list

- Add a row whenever a step, a verifier or QA finds a new gap. Give it the next number. Put it under the right heading.
- When a new package fixes a gap, keep the row. Start its Gap cell with **Done (package YYYY-MM-DD)**.
- If two sources disagree, say so in the row. Do not pick one quietly.
- At the end, turn every row that is not Done into the request to Claude Design.
